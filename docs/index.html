Nabby

Edit BY Black Ring Security

Free and open source SSH terminal and SFTP file manager for Android, inspired by the Tabby desktop terminal. No ads, no tracking, no accounts.

Get it on Google Play Download APK Source code

Terminal

xterm-256color, tabs, extra keys bar with sticky CTRL/ALT, pinch to zoom.

SFTP

Browse, upload, download, edit text files, rename and chmod.

Keys & 2FA

Ed25519, RSA, ECDSA keys, keyboard-interactive login, key generation.

Secure storage

Secrets encrypted with the Android Keystore. Host key verification.

Tunnels

Jump hosts plus local, remote and SOCKS5 port forwarding.

190+ themes

All of Tabby's color schemes, per-host themes, dark and light mode.
