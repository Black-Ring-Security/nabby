# Google Play listing (English)

**App name** (30 max): Nabby - SSH & SFTP Client

**Short description** (80 max):
Fast SSH terminal & SFTP file manager with keys, tunnels and 190+ themes.

**Full description**:
Nabby is a modern SSH and SFTP client for Android, inspired by the Tabby desktop terminal.

TERMINAL
• Full xterm-256color terminal with multiple tabs
• Extra keys bar: ESC, TAB, sticky CTRL/ALT, arrows, HOME/END, PGUP/PGDN, F1–F12
• Pinch to zoom, copy & paste, multi-line paste protection
• Startup commands per host

FILES (SFTP)
• Browse, upload, download and share files
• Built-in text editor for config files
• Rename, move, change permissions, create and delete folders

SECURITY
• Password, private key (Ed25519, RSA, ECDSA) and 2FA / keyboard-interactive login
• Generate Ed25519 keys on your phone
• Passwords and keys encrypted with the Android Keystore
• Host key verification with a clear warning when a server key changes

NETWORKING
• Jump hosts (ProxyJump)
• Local, remote and dynamic (SOCKS5) port forwarding
• Stays connected in the background

STYLE
• 190+ terminal color schemes, per-host themes
• Dark, light and system app theme with accent colors

ORGANIZE
• Groups, favorites, recent hosts and color tags
• Quick connect: type user@host:port
• Import your hosts from Tabby desktop, backup & restore

Free and open source. No ads, no tracking, no accounts.
