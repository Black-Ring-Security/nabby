# Changelog

## 1.0.0

First release.

- SSH terminal with tabs, extra keys bar, pinch to zoom, copy/paste
- Password, private key and keyboard-interactive (2FA) authentication
- Ed25519 key generation, key import, Android Keystore storage
- Host key verification with known hosts
- Jump hosts, local / remote / SOCKS5 port forwarding
- SFTP file manager with text editor
- 192 Tabby color schemes, dark/light themes
- Import hosts from Tabby desktop, backup/restore
- Background sessions with notification and disconnect alerts
- Google Play in-app updates
